What's set up

Plugin registered

gsap.registerPlugin(ScrollTrigger, CustomEase) runs once at startup in main.js.

Fires once

Each reveal plays the first time it enters the viewport and then stays put. It doesn't replay every time you scroll past.

Reduced motion

With reduced motion on, movement is replaced by a short fade. Nothing slides.

Transform and opacity only

Every animation here runs on the compositor. No layout properties are animated, so scrolling stays smooth.
